# File Integrity Checker

## Task 1 - Cyber Security Internship

This project is a Python-based File Integrity Checker.

It uses the SHA-256 cryptographic hashing algorithm to detect whether a file has been modified.

## Features

- Calculate SHA-256 hash of a file
- Create a baseline hash
- Save the baseline hash
- Compare the current hash with the original hash
- Detect file modifications
- Display a warning when a file has been changed

## Requirements

- Python 3
- VS Code

No external Python libraries are required.

## How to Run

Open the terminal in the project folder and run:

```bash
python file_integrity.py
